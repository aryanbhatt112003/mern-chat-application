# 💬 MERN Real-Time Chat Application

A real-time chat application built using the MERN stack. The application allows users to register, log in, and communicate with other users through real-time messaging.

## 📌 Features

- User Registration and Login
- JWT Authentication
- One-to-One Real-Time Chat
- Online/Offline User Status
- Typing Indicator
- Message Seen Status
- Emoji Support
- Image/File Sharing
- User Search
- Responsive Chat Interface

## 🛠️ Built With

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT
- bcryptjs
- Axios
- Bootstrap

## 💬 Application Features

### 🔐 Authentication
Users can register and log in securely using JWT authentication and password hashing.

### ⚡ Real-Time Messaging
Socket.IO is used to send and receive messages in real time.

### 🟢 Online Status
Users can see whether other users are online or offline.

### ⌨️ Typing Indicator
The application shows when another user is typing.

### ✔️ Message Seen Status
Users can see when their messages have been seen.
