💬 MERN Chat Application
A real-time one-to-one chat application built using the MERN stack and Socket.IO. The application allows users to register, log in, view other users, and communicate through real-time messaging.
🚀 Features
User Registration
User Login & Logout
JWT Authentication
Secure Password Hashing
User Profile
Search Users
One-to-One Messaging
Real-Time Messages with Socket.IO
Online/Offline Status
Typing Indicator
Message Seen Status
Emoji Support
Image/File Sharing
Message Timestamps

🧪 How to Test
Start the backend.
Start the frontend.
Open the application in a browser.
Register two different users.
Log in as the first user.
Open another browser/incognito session.
Log in as the second user.
Select a user and send messages.
Test real-time messaging, typing indicator, online status, and seen status.
